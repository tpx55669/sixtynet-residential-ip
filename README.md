## 家宽机和机房 IP 差在哪

同一个商家同时给机房 IP 和家宽 IP 的时候，差距能直接量出来。有机房 IP 的产品，三网直连可用、晚高峰基本不丢包、国际方向上下行能到 2Gbps 以上、到洛杉矶约 10ms；换成家宽 IP，带宽掉到 100Mbps 上行、300Mbps 下行这个量级。差了二十倍。

家宽 IP 换来的是另一套东西：平台认它是真人住宅网络。以 SixtyNet 的 Cox 双 ISP 产品为例，测评记录显示 ipinfo 判定为双 ISP 属性，多个数据库给出原生美国 IP、家宽属性、纯净无风险的结论，流媒体解锁基本全绿。这类 IP 干的是注册账号、过广告验证、跑电商店铺、看地区限定内容这些事。

延迟由机房位置决定，跟商家关系不大。加州家宽到洛杉矶普遍 1–5ms，有测评实测 2.68–4.28ms；夏威夷到洛杉矶约 46ms；台湾 Hinet 到香港中转 28–51ms。选地区比选商家更影响体验。

硬件别按普通 VPS 的标准期待。有测评测过同类家宽机，4K 块写入只有 8.3MB/s，fio 4k 读 7.97MB/s，评价是"性能羸弱，IO 非常低"。SixtyNet 的 Residential 系列用 AMD EPYC 7002 系列加 NVMe，CPU 跑分不差，但有测评明确指出 I/O 相对较弱，可能是官方刻意限制。跑轻量代理、脚本、浏览器自动化够用，拿它当计算节点不合适。

## 直连还是中转：先看你走哪条路

这是 SixtyNet 和大多数便宜家宽机最不一样的地方，也是决定你总花费的关键。

**普通家宽机的直连数据很难看。** 有测评测过台湾 Hinet 家宽晚高峰：深圳电信丢包 16.95%，济南联通虽然 0% 丢包但发送只有 36.0Mbits/sec、重传 7224 次，广东移动发送 4.31Mbits/sec。另一台 SeedNet 产品广东移动丢包 42.13%。美国家宽同样如此，广州联通丢包 12.5%、广州移动 13.5%。配了中转之后，香港或洛杉矶的线路机基本都能跑满机器标称带宽，延迟降到个位数毫秒。

**SixtyNet 的 Residential 系列走的是这条路。** 官方给的是 CN2 GIA 加 CMI 回程，听着不错，但它是家宽 IP 产品，国内访问质量不要期待到线路机的水平。真要稳，还是配一台洛杉矶中转，成本按两台算：$15 的机器加一台入门线路机。

**IRVINE-PRO 系列把中转省掉了。** 它接 AS9929 优化网络，测评记录的三网路由是：电信去程走 CN2 直连洛杉矶，联通去程直连后接 GTT 再接 Cox，移动去程直连移动洛杉矶节点；回程电信和移动走 CN2，联通走 AS10099 加 AS9929。这条线路对国内访问友好，$35/月买到的是"住宅 IP 加能用的国内线路"的组合，省了一台中转机的钱和一层配置麻烦。愿意折腾、想把成本压到最低的人，$15 加中转更划算；不想多管理一台机器、要开箱能连的人，$35 这档值。

## NAT 还是独享：先算清 6 到 7 倍价差

家宽机市场大致分两档。台湾 NAT 共享端口的产品在 ¥20–25/月，典型配置是 1 核 512MB、5GB 硬盘、1000G 流量、300Mbps 共享带宽、无限 IPv4 NAT 端口、无 IPv6。美国或马来西亚的静态独享住宅 IP 在 ¥149/月 或 $35.99/月 这个量级，配置能到 2 核 2G 甚至 4 核 8G，带宽独享 50–100Mbps。

价差 6–7 倍，买的是两样东西：IP 独占，以及不用跟别人抢端口。

- 一个人看流媒体、用 ChatGPT、注册几个账号：NAT 够用，出问题换个端口就行，没必要为独享付溢价。
- 长期固定 IP、多账号矩阵、需要别人主动访问你的服务、跑电商店铺：必须独享。NAT 端口是共享的，别人一滥用，你的 IP 信誉跟着掉。

SixtyNet 走的是独享路线，最低 $15/月拿到独立 IPv4，比 ¥149/月 那档便宜，但比 NAT 贵。它没有 NAT 产品，所以拿它和 ¥20/月的台湾 NAT 比价没意义，两者不是一类东西。
